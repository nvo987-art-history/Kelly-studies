About This Archive

The Kelly Code Studies archive contains official reference case studies supporting the Kelly Code framework.

These studies examine how recognizable identities are formed, maintained, and transferred across changing environments.

Each study demonstrates one or more principles defined within Kelly Code V1 and Kelly Code V2.

The objective of this archive is to provide practical evidence for the theories of Recognizability and Portability.
