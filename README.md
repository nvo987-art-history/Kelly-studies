About

KELLY CODE STUDIES serves as the entry point to the comparative studies, intellectual explorations, and research materials that contributed to the development of the Theory of Identity Survival.

The project investigates why certain identities remain recognizable across changing environments, roles, and systems, while others disappear together with the contexts that originally made them visible.

The studies collected here examine identity through an interdisciplinary perspective that combines cultural analysis, visual systems, historical comparison, and theories of recognition.

Theoretical Framework

The studies contribute to the development of four major stages of the KELLY CODE:

- Kelly Code V1 — The Organizing Principle of Identity
- Kelly Code V2 — Portability and Identity Survival
- Kelly Code V3 — Autonomous Identity
- Kelly Code V4 — Recognizable Systems Beyond Individuals

Central Thesis

«The identities that endure are those capable of remaining themselves amid change.»
